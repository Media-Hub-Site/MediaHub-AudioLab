# AudioLab 🎧⚡

Laboratorio de Síntesis Matemática y Generador Procedural de Efectos de Sonido (SFX) para **Media Hub**.

Desarrollado en **Python Puro con PyQt6** y empaquetado para Windows mediante **PyInstaller (`AudioLab.spec`)**.

---

## 🎯 Características Principales

- **Fórmulas Bytebeat (Live Code):**
  - Síntesis en tiempo real evaluando expresiones matemáticas con la variable de tiempo `t`.
  - Biblioteca con presets legendarios: *Classic 42 Melody (viznut)*, *Cyberpunk Arp*, *Techno Beat*, *Glitch Machine*.
  - Selección de frecuencias de muestreo desde 8000 Hz (8-bit chiptune) hasta 44100 Hz (HQ).
- **Generador Procedural SFX:**
  - Botones interactivos instantáneos con algoritmos acústicos (Burbuja relajante, Moneda/Éxito, Láser arcade, Salto, Explosión, Campana Zen).
- **Osciloscopio Visual:**
  - Gráfico interactivo de la forma de onda en tiempo real con gradiente neón.
- **Exportación WAV:**
  - Exportación directa a archivos estándar `.wav` de 16 bits para usar en juegos, launchers o notificaciones.
